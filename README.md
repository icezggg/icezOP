# 🚀 icezOP - Windows Toolkit
Herramienta avanzada para optimización e instalación de software en Windows 10 y 11.

✨ Características
🎨 Interfaz de diseño oscuro con acentos morados, tarjetas dinámicas y motor asíncrono (la UI nunca se congela).
📦 Instalador de Apps: Descarga e instala automáticamente más de 80 programas usando Winget.
⚙️ Optimizaciones y Tweaks: Aplica más de 30 ajustes de registro y sistema para mejorar el rendimiento, la privacidad (desactivar telemetría) y el ping en juegos.
🛡️ Seguridad Automática: Crea un punto de restauración del sistema automáticamente al abrir el programa.
🛠️ Cómo usarlo
Descarga el archivo .zip de la sección Releases.
Extrae la carpeta en tu Escritorio.
Haz doble clic en Abrir_Toolkit.bat.
¡Acepta los permisos de administrador y empieza a optimizar tu PC!
⚠️ Advertencia
Algunos tweaks del módulo "Experimental" o de "Servicios" pueden desactivar funciones de Windows que algunos usuarios necesitan (como Windows Search o Print Spooler). Úsalos bajo tu propio riesgo.

Creado con PowerShell y WinForms.
